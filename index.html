Pre-Execution Agent Qualification (PEAQ)

A Framework for Task-Criticality-Aware AI Agent Deployment

Independent AI safety research project · Jun 2026 – Present

  • Proposed a pre-execution qualification gate placed before an agent's planner and tool selector, so an agent must be qualified before it is allowed to plan or act, not only checked after it proposes an action.
  • Built a two-layer safety framework combining an offline Agent Trust Score with a deterministic OPA/Rego runtime gate, evaluated on a unified benchmark schema integrating AgentHarm, InjecAgent, ToolEmu, tau-bench, and SWE-bench.
