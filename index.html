I work on AI safety. I study when AI agents should be allowed to act and whether language models change their answers for good reasons.

My recent work has two threads. PEAQ is a deterministic gate that decides whether an agent may start an action before it plans or calls a tool. FlipRate measures whether a model changes its answer because the user is right or only because the user pushed. I also build full-stack software, mostly in Python, Java and TypeScript.

FlipRate: do language models update because the user is right, or because the user pushed?

2026

Naveen Ragav · Research report, Apart Research AI × Epistemics Sprint

Models answer MMLU-Pro questions and then face three escalating rebuttals: doubt, a confident claim, and an appeal to authority. When the model was right, the user pushes toward a wrong option. When it was wrong, the user pushes toward the correct one. A no-pushback control and a Latin-square order ablation separate the kind of pressure from the amount of it.

  • Across three open-weight models, discrimination (update rate minus capitulation rate) was 0.67 to 0.70.
  • An appeal to authority alone flipped 42–57% of correct answers in the first round. Plain doubt flipped 0–4%.
  • Three doubts in a row flipped at most 6% of correct answers, so repetition alone was not the cause.

PEAQ: Pre-Execution Agent Qualification

2026

Naveen Ragav · Research framework and evaluation

Most agent safety work intercepts at runtime, after the agent has already planned. PEAQ moves the decision earlier. It classifies the request, resolves a trusted context from records the request cannot alter, checks typed hard constraints, and returns approve, conditional approve, human review or reject. No LLM judgment is involved in the decision.

  • Evaluated on 2,191 cases from six public benchmarks (AgentHarm, InjecAgent, ToolEmu, τ-bench, SWE-bench, AgentDojo) across five agent domains.
  • On the held-out split, the hard constraints alone caught 98.3% of unsafe cases. The trust score added little, which the write-up reports as a limitation.
