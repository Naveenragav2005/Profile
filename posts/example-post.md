## How to write a post

Write in Markdown. The title, date and summary come from `posts.json`, so start the file with your first paragraph, not with a heading.

- Use `##` for section headings.
- Use **bold** and *italic* as usual.
- Add links like [this one](https://example.com).

> Quotes look like this.

```python
def hello():
    return "Code blocks are supported"
```

## Images

Put the image in the `posts` folder and reference it like this: `![A description](posts/my-image.png)`.
