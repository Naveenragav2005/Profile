Research

What I work on

CS graduate focused on AI agent safety, evaluation methodology, and reliable autonomous systems.

Research interests

  • 01

    AI agent safety

    Deciding whether an agent should be allowed to plan or act at all, before it does.

    • Pre-execution qualification gates
    • Task-criticality-aware deployment
    • Policy-as-code runtime gates (OPA/Rego)
    • Human override for high-sensitivity actions
  • 02

    Evaluation methodology

    Measuring agent safety in a way that holds across benchmarks.

    • Unified benchmark schemas
    • Agent trust scoring
    • Safety benchmarks: AgentHarm, InjecAgent, ToolEmu
    • Task benchmarks: tau-bench, SWE-bench
  • 03

    Mechanistic interpretability

    Understanding what a model computes internally, not only what it outputs.

    • Circuit analysis
    • Sparse autoencoders and feature discovery
    • Activation patching
    • Interpretability for safety-relevant behaviour
  • 04

    Reliable autonomous systems

    Multi-agent systems that stay dependable when given real autonomy.

    • Multi-agent orchestration
    • Cross-agent verification of proposed actions
    • Human-in-the-loop oversight
    • Explainable model decisions (SHAP)

Publications

  1. NeurIPS 2026 WorkshopAccepted Pre-Execution Agent Qualification (PEAQ): A Framework for Task-Criticality-Aware AI Agent Deployment
    • Proposed a pre-execution qualification gate placed before an agent's planner and tool selector, so an agent must be qualified before it is allowed to plan or act, not only checked after it proposes an action.
    • Built a two-layer safety framework combining an offline Agent Trust Score with a deterministic OPA/Rego runtime gate, evaluated on a unified benchmark schema integrating AgentHarm, InjecAgent, ToolEmu, tau-bench, and SWE-bench.
  2. IJIRTJournal paper Depression Subtype Classification Using Hybrid ML Models
    • Built hybrid CatBoost–Neural Network and LightGBM–Neural Network models (PyTorch) to classify Bipolar I, Bipolar II, and Unipolar depression from minute-level wearable actigraphy and clinical data, reaching 95.38% accuracy and 0.997 ROC-AUC with the best-performing model.
    • Built SHAP-based explainability tooling and a Streamlit interface to compare model outputs and surface the clinical and behavioral features driving each prediction.
  3. IEEE ICNGCS 2025Conference paper Financial Tracking System for Civil Construction
    • Built a financial tracking platform to monitor expenses and control budgets on civil engineering projects, using React Native for the frontend, Flask/FastAPI for the backend, and MySQL for data management.
    • Implemented a Random Forest regressor achieving 99% R² in predicting final project costs and flagging potential budget overruns, improving financial transparency and supporting decision-making.
